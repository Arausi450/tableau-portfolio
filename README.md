## Working Method

- The title states the finding, so each dashboard can be read from its headline.
- The palette, type and layout change from one dashboard to the next instead of repeating a template.
- Every workbook goes through Tableau's Workbook Optimiser before it is published.

## How This Repository Is Organised

One folder per dashboard, numbered in the order they were published. Each folder holds a short README with the subject, the data source where it is credited, the month it was published and a link to the live version.
